# 05 — 三栏工作台布局 + VSCode 式面板收放 + 响应式切换

**What to build:** 页面升级为宽屏三栏工作台——左栏大纲占位、中栏 Markdown 编辑、右栏树形图，栏间留出间距并以带 ⋮ 握把的分隔条拖拽调宽（默认 240/自适应/280）；推到底（<64px）自动收起为边缘条，侧边浮现竖排恢复图标（VSCode 式），点击或反向拖拽恢复上次宽度；面板宽度与收起状态存 localStorage 刷新保留；视口 <720px 时自动切换为单栏聚焦布局。交互模型以 `prototype/layout-mock` 分支为验收基准。
