# 07 — 大纲多选 + 浮动工具栏（同父约束）

**What to build:** vendor SortableJS 并落地多选模型——checkbox 点选切换；Shift 连选仅限同级（同父约束），越界部分自动截断到同父范围并在状态条提示；工具栏「全选」选中所有顶级节点（等效整棵树）；选中父节点时其后代自动跟随；选中 ≥1 项时顶部浮出「n selected」工具栏，提供缩进/取消缩进/删除操作，全部满足同父约束语义（见 ADR-0001）。

**Blocked by:** 06 — 大纲视图基础渲染 + 行内编辑

**Status:** ready-for-agent

- [ ] SortableJS vendor 引入；checkbox 多选/取消，选中态视觉清晰
- [ ] 同父约束生效：跨父节点不可同时处于选中态；选中父节点即等效选中整棵子树
- [ ] Shift 连选越界时截断到同父范围，状态条给出一句提示
- [ ] 全选 = 选中所有顶级节点（后代跟随）
- [ ] 「n selected」浮动工具栏：缩进/取消缩进/删除对选中集生效，结果回流中间树并刷新其余视图
- [ ] 手动验收：参考用户提供的 Notion 截图形态逐项对比（多选、浮动栏、批量删除）
